# @gitsang/dsh-session-tree

新增独立的 **轨迹树** Tab，以 git graph 方式画出会话分支血缘，并支持从任意持久事件分叉会话。

## 功能

- **独立轨迹树 Tab**：作为 Conversation View 注册在 Chat、Trajectory 旁边，不再往原生轨迹 DOM 注入任何东西。
- **git 式 lane**：你打开的这个会话被重新视为主干 lane 0。祖先会话的其它分叉、以及旧主线在该分叉之后的继续，都显示为侧 lane；查看分叉会话时会明确标出 `原主线继续`。只会有分叉，不会有合入。
- **沿用 DSH 视觉**：和 Trajectory 一样的 30px 行高、类型胶囊、边框和弱化色；`第 N 轮` 和 Trajectory 一样贴在每轮第一行的左上角，不单独占一行。
- **展开 / 收起**：每个侧分支分叉点有 `−/+` 节点，可折叠整棵子分支，并显示隐藏了多少行。
- **完整 family**：展示整棵连通会话树，而不只是当前会话的后代。
- **任意事件分叉**：每条事件行都有「从此后分叉」；时间线底部还可输入精确事件序号。
- **编辑已发送消息**：铅笔按钮就在宿主原有的「复制」按钮旁边。Host 会从该轮次之前分叉，然后把修改后的消息发进新会话。
- **不替换 Chat 渲染器**：组件只往原生操作行里插入两个同级按钮，保留「复制」和其他宿主控件。
- **打开任意分支**：单击卡片查看，双击或点「打开」切换过去；已归档分支会先取消归档。

原会话永远不会被改写。每条分支都是通过 `session.fork` 创建的普通原生 DSH Session。

## 安装

随 bundle 安装：

```bash
dsh plugin --profile web add ~/src/github.com/gitsang/dsh-qol
```

然后在 **Plugins** 中启用 `@gitsang/dsh-qol`。本组件显示为 `@gitsang/dsh-session-tree`，可单独开关。

单独安装：

```bash
dsh plugin --profile web add @gitsang/dsh-session-tree
```

安装后重启 profile；只改 UI 时刷新浏览器即可。

## 使用

1. 打开一个已有对话，切换到 **轨迹树**。
2. 你打开的会话作为主干显示；即使它原本是 fork 出来的，也会被重新视为主线；祖先的其它分支和旧主线继续作为侧 lane 显示。
3. 编辑旧消息：点用户消息原生「复制」按钮旁边的铅笔。保存后会从该轮次之前分叉并发送修改后的文本。
4. 从当前分支最新事件分叉：使用用户消息上的分支按钮。

## 语义

| 操作 | 分叉边界 | 之后 |
| --- | --- | --- |
| 用户消息上的分叉按钮 | 该用户消息对应事件（包含） | 打开新会话，不发消息 |
| 编辑用户消息 | 该轮 `turn/start` 之前的事件 | 分叉，恢复原模型路由，发送修改后的文本 |

分叉前默认会取消源会话正在生成的回复，避免被取代的回答继续消耗额度。

## 性能

- Host 路由读取完整 Session 日志；浏览器按 Session 缓存最近一次分支投影，重新打开会话时先立即绘制再后台刷新。
- 树是一个普通 React View，只从一份投影渲染，不观察也不修改原生 Trajectory DOM。

## 限制

- 编辑只保留**文本**。原用户消息里的图片、文件不会重新上传到新分支。
- 对话分叉不会回滚工作区文件、命令、Git 状态、进程或其他工具副作用。
- 树接口读取完整 Session 日志；单次响应最多展示 100 个会话。
- DSH 仍是预发布软件。本包面向 DSH `0.2.x` 暴露的 Session Controller、Session Query 与 Workspace 服务。
